# VW — Punch Buggy App Concept

An interactive iPhone-app mockup for a Punch Buggy game, based on the rules from
*Punch Buggy: The (Previously) Unwritten Rules of the World's Most (Violent) Fun
Family Game* by Nicole Reineke.

Open `index.html` in a browser to try it — it's a clickable prototype of the core
screens: a cross-country family rivalry (Score, Trip, Team, History, Rules), a
personal Bug-Dex and global weekly/annual leaderboard that run alongside the
rivalry, official 1973 VW factory colors, and a first-to-21 round with a
celebration screen when someone wins.

To view it live on the web, enable GitHub Pages for this repo (Settings → Pages
→ Deploy from branch → this branch, folder `/`).
